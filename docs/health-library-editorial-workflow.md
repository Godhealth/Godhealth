# GodHealth Health Library — editorial workflow

## Mission
Provide useful Christian health education grounded in Scripture and reliable health evidence. Do not promise cures, spiritual outcomes or rankings.

## Publication gates
1. Identify search intent and existing overlapping URLs. Improve an existing page rather than creating duplicates.
2. Record author, target audience, outline and scope.
3. Record each substantive health claim with a primary guideline or systematic review where available, publication date, URL/DOI and limitations. Read the source before citing it.
4. Check every Bible quotation against KJV and its surrounding context. Separate theological interpretation from empirical evidence.
5. Require a qualified professional's documented review for medical topics, including lab interpretation, chronic illness, medication, hormonal health and high-risk fasting. Hold publication if unavailable.
6. Disclose commercial interests and distinguish coaching from medical care. Never invent credentials, outcomes or reviews.
7. Check title, description, canonical, internal links, accessibility, mobile layout, status code and structured data. Use Article markup only for genuine articles.
8. Publish only after approval; update sitemap lastmod only for meaningful changes.
9. Monitor Search Console by page, query and country; review accuracy when guidance changes. Maintain correction history.
